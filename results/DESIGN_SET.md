# Design set: which ASAP7 designs the harness can use

Generated by `harness/probe_designs.py` (synthesis-only, resyn2 recipe injected via
the ABC (And-Inverter Graph optimizer) script override). Synthesis is the cheap
gate: a design that fails here cannot be used at all, and one that passes is a
candidate for the expensive full place-and-route sweeps.

7nm predictive Process Design Kit) designs synthesize cleanly, with zero synthesis
errors and the recipe override honored on every one.

## Correcting the earlier "only three designs" note

`results/RESULTS.md` and `harness/make_report.py` state that only gcd, uart and aes
synthesize cleanly. That limit was in the **proxy AIG extraction path**
(`harness/aig.py` / `harness/gnn_data.py`, a Yosys-only route used to build the GNN
(Graph Neural Network) training graphs), not in the real ORFS flow. Through the real
flow, all twelve synthesize. The corrected, larger set is what the real-QoR (Quality
of Results) sweeps use.

## Route corpus (confirmed end-to-end, 2026-09-18)

Full place-and-route is far more expensive than synthesis. The two large CPU cores
(cva6 at 100k instances, swerv_wrapper at 94k) dominate route time and add little
structural diversity beyond ibex and riscv32i, so they are held out of the default
route corpus and kept as an optional stretch set.

Running resyn2 through the FULL flow on the ten small-to-medium designs, **nine
routed end-to-end**:

    aes, ethmac, gcd, ibex, jpeg, mock-alu, mock-cpu, riscv32i, uart

**aes-block dropped.** It synthesizes cleanly but fails floorplan macro placement
(`[ERROR MPL-0003] There are no valid tilings for mixed cluster: root`). It carries
hard macros whose floorplan needs special handling; this failure is independent of
the ABC (And-Inverter Graph optimizer) recipe (the stock flow fails it the same
way), so it is not a recipe-study design.

The nine-design route corpus is what the real-QoR (Quality of Results) sweeps use.
The resyn2 baseline QoR for these nine is recorded in `results/BASELINE.md`.
